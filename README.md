# Electrónica en Corto · Medios aprobados

Alojamiento estático separado para **videos de Electrónica en Corto expresamente aprobados** para difusión pública.

## Seguridad
- Este repositorio **no** contiene el código fuente del Studio, secretos, credenciales, informes privados ni borradores.
- **No subir** ningún episodio sin revisión humana y autorización expresa del video exacto (SHA-256).
- Solo los MP4 aprobados estarán en `videos/`. Toda subida a este repositorio será pública cuando se cambie la visibilidad a *Public*.
- El archivo inicial `index.html` es una página informativa: **no** lista archivos ni publica videos automáticamente.
- El sitio se configura en **Settings → Pages → Deploy from a branch → main → /(root)** después de cambiar la visibilidad a *Public*.
- La URL de alojamiento esperada, después de habilitar Pages, es `https://jonathancb247-cyber.github.io/electronica-en-corto-media/`.
- Los videos publicados deben tener nombres deterministas `videos/<episodio>-<sha256primeros16>.mp4` y conservarse accesibles hasta que Buffer termine de procesarlos.

No se autoriza publicación automática en TikTok o Buffer por el solo hecho de almacenar un archivo aquí.
